# Jarvis project rules

- At the start of every session, read JARVIS_BRIEF.md, about_me.md and jarvis.py before doing anything else.
- JARVIS_BRIEF.md is the master plan. Follow all its rules, safety rules and stage order.
- Work on one stage at a time, give a short plan first, and ask permission before editing any file.
- Never break features that already work. Back up files before big edits.
